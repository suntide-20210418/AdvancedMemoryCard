# 高级内存卡

<ItemImage id="advanced_memory_card:advanced_memory_card" scale="4" />

高级内存卡是标准[内存卡](ae2:items-blocks-machines/memory_card.md)的增强版本，为Applied Energistics 2系统提供强大的自动化配置能力。它能够简化重复性的配置任务，并实现设备设置的高效批量部署。

与标准内存卡不同，高级内存卡具备**复制模式**和**配置模式**两种操作模式，使大规模AE2网络管理变得更加高效。

## 合成配方

<RecipeFor id="advanced_memory_card:advanced_memory_card" />

将1个AE2内存卡与逻辑处理器、计算处理器、工程处理器各一个无序合成即可获得。

## 基本操作

- 手持高级内存卡时，按 **V 键**（可在按键设置中修改）在复制模式和配置模式之间切换
- 复制模式下按 **G 键**（可在按键设置中修改）打开「粘贴选项」面板
- 物品提示栏会显示当前所处的模式及状态信息
- 复制模式下，**右键点击空气** 执行批量粘贴操作

# 复制模式

复制模式允许您将一个设备的配置批量复制到指定矩形区域内的所有兼容设备上，大幅提升大规模AE2网络部署的效率。

## 使用流程

1. **Shift + 右键** 点击一个AE2设备，复制其配置设置（与普通内存卡相同）。复制会覆盖卡片上原有的导出内容；若开启了自动弹出（默认开启），此时会弹出下文「粘贴选项面板」里说明的选项界面
2. **右键点击** 方块的第一个角落，标记为区域起始点
3. **右键点击** 对角线的另一个角落，标记为区域结束点
4. **右键点击空气**，将存储的配置批量粘贴到选定区域内所有兼容设备

## 粘贴选项面板

粘贴时「具体应用哪些内容」由面板里的 8 个开关控制，每个开关对应一种 AE2 导出数据：

| 选项 | 对应数据 | 说明 |
| --- | --- | --- |
| 升级 | 升级卡 | 设备的升级卡槽 |
| 设置 | 通用配置 | 可配置对象（如输出面、模糊模式等）的配置项 |
| 优先级 | 优先级 | 存储总线、接口等的优先级 |
| 配置物品 | 配置槽 | 过滤/标记物品等配置槽内容 |
| 样板 | 样板 | 样板供应器的样板 |
| P2P 类型 | P2P 类型 | P2P 隧道类型（决定部件是否被换成另一种隧道） |
| P2P 频率 | P2P 频率 | P2P 隧道绑定的频段 |
| 名称 | 自定义名称 | 设备/部件的名称 |

### 打开方式

- 手持卡片且处于复制模式时按 **G**；
- 默认在**每次复制时**（Shift + 右键把设备配置复制进卡片）自动弹出，前提是目标确实是 AE 方块或线缆部件。

### 自动弹出开关

面板左侧竖排工具栏里的按钮控制「复制后是否自动弹出本面板」：

- **亮起**：每次复制后自动弹出面板
- **灰化**：复制后不弹出，只能用 G 键手动打开

把鼠标悬停在该按钮上会显示「每次复制后自动弹出本界面」。开关状态与勾选结果一样，**按卡片保存**，右键空气或切换模式都不会丢失。

### 默认值与保存

- 从未配置过的卡片默认**全部不选**：粘贴不会应用任何项，需要在面板里显式勾选
- 勾选结果写在卡片上，之后每次弹出都沿用上次的选择
- 选项与当前模式无关：切到配置模式再切回来，勾选状态不会重置

### 「不应用」的含义

勾掉某一项后，该项不会被写入目标设备，目标保持自己的原值。

其中**样板 / P2P 类型 / 名称**三项在 AE2 的实现里把「数据缺失」当作「清空目标」（名称被置空、样板被清空、P2P 类型分支整段不执行），所以粘贴时会把**目标自身的当前值**回填进去，效果等同于保持原样，而不是把目标清空。

## 功能特点

- 区域体积上限默认为 **2048 个方块**，可在服务端配置 `maxCopyVolume` 中修改
- 适用于所有AE2方块实体（ME接口、存储总线、输出总线等）
- 兼容安装在线缆上的AE2部件（破坏平面、成型平面、P2P通道等）
- 选择区域过大时自动提示错误并重置选择
- 粘贴完成后自动清除选择状态

## 视觉指示器

选择区域会以彩色线框实时渲染在世界中：

- **起点方块（红色）**：已标记第一个角，此时从起点到准星会显示一条**白色**橡皮筋框，等待标记对角
- **终点方块（黄色）**：第二个角已标记，整个选区显示为**绿色**框，表示可以粘贴
- **准星方块（绿色）**：尚未标记终点时，准星指向的方块会单独高亮
- **超范围（红色）**：橡皮筋框的预计体积超过上限时，框会变成红色提示

方块高亮的颜色在客户端配置的 `[client.copyColors]` 段（`startPos` / `endPos` / `targetedPos` / `overLimit`）；线框本身的颜色跟随选择状态，在 `[client.selection]` 段（`first` 红 / `second` 白 / `ready` 绿）。

# 配置模式（P2P 隧道管理）

配置模式是高级内存卡的强大P2P隧道集中管理工具。它能够扫描AE2网络中所有的P2P设备，并提供可视化的管理界面。

## 打开配置模式

手持卡片在配置模式下，**右键点击** AE2网络中的任意P2P隧道部件，即可打开P2P管理GUI。

## GUI 界面布局

P2P配置模式界面分为三个主要区域：

### 左侧：P2P树形控件
- 按 **P2P类型 → 频段 → P2P设备** 的三层树形结构展示所有P2P设备
- 每个P2P设备前有状态图标指示其连接状态：
  - **🟢**：已激活且已连接
  - **🔴**：已激活但未连接
  - **⭕**：未激活
- 📥（蓝色）标记输入端，📤（黄色）标记输出端
- 待绑定的P2P设备名称显示为紫色加粗，并在末尾带一个 ◆
- 顶部搜索框支持按类型、频段、名称、频段别名过滤

### 右侧：详情面板
根据选中节点的类型显示不同的信息和操作按钮：

**P2P设备节点**：
- 显示名称（可编辑）、频段、类型、维度、坐标、方向、连接状态
- 对于ME P2P，额外显示频道占用（头部「已用/总数」chip 与底部占用条）
- 操作按钮：高亮（关界面 + 世界内高亮 + 转头朝向目标）、改名、分配新频段、传送（仅在服务端开启 `allowTeleport` 时显示）

**频段节点**：
- 显示频段别名（可编辑）、P2P数量、频道信息
- 输入/输出端统计
- 操作按钮：高亮（关界面 + 高亮整个频段 + 转头朝向第一台输入端；聊天栏会列出两端成员）、改名、绑定（把配对源绑到这个频段）；频段本身没有位置，因此不提供传送

**P2P类型节点**：
- 显示类型名称、P2P总数、频段总数
- 对于ME P2P类型，提供"初始化P2P"按钮，自动配置所有未分配频段的ME P2P设备的输入/输出角色
- 操作按钮：初始化P2P（仅ME类型）、刷新；类型行只是分组标题（单击它只展开/折叠），不提供高亮与传送 —— 这两件事都需要先选中一台具体设备

### 底部：操作条
- 左侧是当前操作提示，如"选中设备 → 选中频段 → 绑定"
- 右侧是「批量操作」与「绑定」两个按钮

## 核心功能

### 批量操作与框选
- 按住 `Ctrl` 在某一行按下左键上下拖动，划过（覆盖到）的设备会**改变选中状态**：从一台未选中的设备起手是「扫过即选中」，从一台已选中的设备起手是「扫过即取消选中」，整段拖动只朝一个方向走。从频段行起手时整条频段一起算（折叠着也一样）。每次拖动都从按下瞬间的快照重算，往回拖能还原被扫过的行；只收同类型设备。
- 底部「绑定」左边有「批量操作」按钮：点一下进入批量模式，按钮文字变为「退出批量操作」并点亮，再点一次才退出。模式里不用按着 `Ctrl`：单击设备就是加选 / 取消加选，按住左键拖动照样框选；点或拖到频段行都会把该频段下所有设备一起选中，整条已全选时再点一次整条取消。
- 批量模式下频段行的展开 / 折叠改用**右键**（左键已被选中设备占用）。
- 按住 `Ctrl` 点频段行或类型行也能直接进入批量模式；类型行始终只负责展开折叠，不选设备。
- 多选只允许同类型，第一台设备成为输入端、其余成为输出端。退出批量模式不会清空已选设备。

### P2P 设备绑定
1. 在树形控件中单击一台设备，它成为顶部配对条的「源」
2. 在树上或目标槽的下拉里选一个频段（没有合适的就选「新建频段…」）
3. 点底部右下角的「绑定」（或按回车）完成绑定
4. 想一次绑多台时，先按住 `Ctrl` 多选（或用「批量操作」模式），第一台成为该频段的输入端、其余成为输出端；绑完目标频段会保留，方便接着绑下一批

### 自动配置 ME P2P I/O
点击P2P类型节点中的"初始化P2P"按钮，系统会自动：
- 检测每个ME P2P所在网络是否有ME控制器
  - 有控制器 → 设置为输入端
  - 无控制器 → 设置为输出端
- 为未分配频段的P2P自动分配新频段

### P2P 高亮与传送
- 点击"高亮"按钮后，GUI会关闭并在世界中以彩色线框渲染目标设备（默认持续 5 秒，可在客户端配置 `p2pHighlightDurationSec` 中修改）
- 红色框：当前目标设备
- 绿色框：该频段的输入端
- 蓝色框：该频段的输出端
- 高亮后视角会自动转向目标设备（客户端配置 `rotateHeadOnHighlight` 可关闭转头）
- 服务端配置 `sendHighlightToChat` 设为 false 时不再输出聊天栏信息，世界内高亮仍然生效
- 频段节点的高亮会在聊天栏列出该频段的全部成员：输入端一段、输出端一段，每行带「输入」/「输出」标记与维度坐标
- 开启服务端配置 `allowTeleport` 后，设备行的第 4 格会多出一个「传送」按钮，由服务端直接把玩家送到该设备位置（支持跨维度，实心宿主块会落到顶面）；落位后会自动点亮这台设备并把视角转向它。类型行不提供这个按钮。

### 重命名
- P2P设备节点：可修改设备名称，方便在大规模网络中识别
- 频段节点：可设置频段别名（实质为修改该频段输入端P2P的名称）

### 分配新频段
对于非ME类型的P2P设备，点击"分配新频段"按钮会：
- 断开当前连接
- 将设备设为输入端
- 分配一个新的唯一频段

# 兼容设备

## 复制模式兼容
所有支持AE2内存卡设置的设备和部件，包括但不限于：
- ME接口 (ME Interface)
- 存储总线 (Storage Bus)
- 输入/输出总线 (Import/Export Bus)
- 液位发射器 (Level Emitter)
- 能源接收器 (Energy Acceptor)
- 破坏/成型平面 (Annihilation/Formation Plane)
- 分子装配室 (Molecular Assembler)
- P2P通道 (P2P Tunnel)

> 具体某一项能否写入，取决于该类设备是否实现了对应的 AE2 设置接口（升级卡 / 通用配置 / 优先级 / 配置槽 / 样板），不支持的类型会被自动跳过。

## 配置模式兼容
AE2网络中所有类型的P2P隧道部件：
- ME P2P通道
- 物品 P2P通道
- 流体 P2P通道
- 红石 P2P通道
- 能源 P2P通道
- 光 P2P通道
- 以及所有其他P2P类型
