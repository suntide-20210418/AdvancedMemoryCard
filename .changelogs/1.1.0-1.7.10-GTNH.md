# Advanced Memory Card 1.1.0 (1.7.10 / GTNH)

支持 Minecraft 1.7.10 + Applied Energistics 2 (GTNH · rv3)。客户端与服务端都需要安装。

## 新功能

- **粘贴选项面板**：复制模式下新增 7 项可勾选的粘贴内容（设置、优先级、配置物品、样板、P2P 类型、P2P 频率、名称），以及「复制后自动弹出」开关。按 `G` 打开。
- **选择性粘贴**：只把勾选的项写进目标，未勾选的项保持目标原值。此前是整包覆盖。
- **潜行右键复制**：对 AE 方块、AE 部件、P2P 隧道都可用；复制成功后按设置自动弹出选项面板。
- **P2P 高亮**：颜色改由客户端配置解析，服务端只下发「自身 / 输入端 / 输出端」语义，多人环境下不再使用服务端的颜色值。

## 修复

- 修复右键被 AE2 原生内存卡逻辑接管：AE 方块上的点击不会进入本模组代码，表现为「就是原版内存卡」。现在在 `PlayerInteractEvent` 层接管，客户端与服务端各走自己的包。
- 修复潜行右键会清空整张卡：AE2 的 `ToolMemoryCard#onItemUse` 在潜行时执行 `setTagCompound(null)`，会把模式与粘贴选项一起抹掉，导致卡片悄悄退回默认模式。
- 修复打开本模组 GUI 后右键方块导致服务端崩溃（`Cannot read field "slotNumber" because "slot" is null`）：容器补上屏幕外的玩家背包槽位。
- 修复频段改名不生效：改名确认走了错误分支，请求根本没发出；同时为查找失败补了回退路径，并在改名后标记宿主保存。
- 修复 P2P 树按频段排序时的 `NumberFormatException`（频段是 64 位，不能用 `Integer.parseInt`）。
- 修复工具提示里 `\n` 原样显示的问题。

## 交互约定

- 右键**方块**：复制模式打点 / 配置模式打开面板
- 右键**空气**：粘贴
- **V**：切换复制 / 配置模式
- **G**：打开粘贴选项

## 已知限制

- 跨类型 P2P 换型在 AE2 rv3 上没有就地修改入口，需要拆件重建；不支持的组合会被跳过并在结果里提示跳过数量。
