# Advanced Memory Card 高级内存卡

**简体中文** | [English](README_en.md)

一个 Applied Energistics 2（AE2）扩展模组，为 AE2 内存卡提供**区域批量粘贴**与**P2P 通道集中配置**两大能力。

> **当前版本：`1.2.0-1.21.1`** · Minecraft 1.21.1 / NeoForge 21.1.219+ / AE2 1.21.1 版本线
> 更新内容见 [CHANGELOG.md](CHANGELOG.md)。

## 🌟 功能特性

### 🔧 两种工作模式

模式与卡片级偏好都存在物品的 `CUSTOM_DATA` 组件里（`mode_data` 加上若干偏好键），可随时切换：

| 模式 | 说明 |
| --- | --- |
| **复制模式（Copy Mode）** | 先把一个 AE2 设备的配置复制进卡片，再框选区域，把配置批量粘贴到区域内所有 AE2 方块与部件 |
| **配置模式（P2P 通道管理）** | 对着 P2P 隧道部件右键打开图形界面，集中管理与配置当前 AE 网络内的 P2P 通道 |

### 📋 复制模式（Copy Mode）

- **区域批量粘贴**：Shift + 右键复制单个 AE2 设备的配置 → 右键标记两个对角方块 → 右键空气批量应用。
- **方块与部件都覆盖**：区域内所有 `AEBaseBlockEntity`（ME 控制器、接口、存储总线等）与 `IPartHost` 上的所有部件都会被处理。
- **体积上限保护**：区域体积超过服务端配置 `maxCopyVolume`（默认 2048 个方块）时会被拒绝并重置选区，避免误选超大范围卡顿。
- **可视化选区**：起始点、结束点、准星指向的方块、超范围的方块各自使用独立配色。
- **实时状态提示**：物品 tooltip 与聊天栏显示已标记坐标、区域大小、粘贴完成的方块数量。

#### 粘贴选项（8 项，按卡保存）

粘贴时具体应用哪些内容由 8 个开关控制：

| 选项 | 对应数据 | 说明 |
| --- | --- | --- |
| 升级 | 升级卡 | 升级卡槽 |
| 设置 | 通用配置 | `IConfigurableObject` 的通用配置 |
| 优先级 | 优先级 | 优先级 |
| 配置物品 | 配置槽 | 配置槽内容（过滤/标记物品等） |
| 样板 | 样板 | 样板供应器的样板 |
| P2P 类型 | P2P 类型 | P2P 隧道类型（决定部件是否换型） |
| P2P 频率 | P2P 频段 | P2P 隧道绑定的频段 |
| 名称 | 自定义名称 | 自定义名称 |

- **打开方式**：手持卡且处于复制模式时按 `G`（默认键位，可在控制设置中修改）；默认在**每次复制时**（Shift + 右键把设备配置复制进卡片）自动弹出。
- **自动弹出开关**：面板左侧（挂在面板外的竖排工具栏里）有一个开关按钮 —— 亮起 = 每次复制后弹出，灰化 = 不弹出，状态同样按卡保存。
- **首次默认全不选**：从未配置过的卡片默认不应用任何项，需要显式勾选；勾选结果写在卡片上，之后每次弹出都沿用。
- **「不应用」= 目标保持原值**：勾掉某项后，该项不会被写入目标。其中样板 / P2P 类型 / 名称三项在 AE2 的实现里「数据缺失 = 清空目标」，所以粘贴时会把目标自身的当前值回填，效果等同于保持原样。
- **与模式切换无关**：选项存在卡片根标签（`mode_data` 之外），切换模式、重新复制都不会被重置。

### 🕸 配置模式（P2P 通道管理）

对着任意 **P2P 隧道部件**右键即可打开配置界面，对当前 AE 网络内的所有 P2P 设备进行可视化管理：

- **配对条（源 → 目标）**：界面顶部常驻一条配对栏。左侧是「源设备」（会被绑走的那一台），右侧是「目标频段」，中间箭头在两者齐备时点亮。点源槽的 × 可把配对源退回打开界面时右键的那一台。
- **列式 P2P 列表**：自动扫描所在网络，按类型 / 频段 / 设备三级展示，四列分别是状态点、名称、频段、汇总。汇总列的含义按行类型区分：频段行是「台数 + 剩余频道」，**ME 设备行显示频道占用并带「入 / 出」前缀**：输入端是它自己外部网络的已用/总数；输出端是「本输出已用 / (输入端剩余 + 本输出已用)」，分母表示这条频段还能分给它的份额度，输入端与非 ME 设备显示输入/输出角色；非 ME 频段没有频道概念，只报台数。类型行用部件译名（如「ME P2P 隧道」），不再直接画资源路径。支持展开折叠、搜索过滤，名称超宽按像素截断并加省略号。
- **频段下拉**：点目标槽（或它的下拉箭头）弹出频段列表，直接选一个即可；列表按频段号排序，只列与当前源设备**同类型**的频段，底部是「新建频段…」。**再点一次目标槽即可收起列表**，点别处也会收起。
- **Ctrl 多选批量绑定**：按住 `Ctrl` 点选多台设备（只允许同类型；点到不同类型的设备时，之前选中的会全部取消），源槽显示「已选 N 台」，底部提示「把 N 台设备绑定到 0A1B，回车确认」即可一次绑完。服务端逐台绑定，第一台会成为该频段的输入端，其余成为输出端。
- **Ctrl 拖动框选**：按住 `Ctrl` 在某一行按下左键往上或往下拖，划过（覆盖到）的设备会**改变选中状态** —— 从一台未选中的设备起手是「扫过即选中」，从一台已选中的设备起手是「扫过即取消选中」，整段拖动只朝一个方向走；**从频段行起手时整条频段一起算**（输入端与输出端全进，频段折叠着也不必先展开）。往回拖会把多出来的行还原，划过类型标题则不会把整个类型选上；同样受「只允许同类型」约束，拖出列表上下边界只停在最边上一行，不会选中滚出视野的设备。
- **批量操作模式**：底部「绑定」左边有「批量操作」按钮，点一下进入批量模式（按钮变为「退出批量操作」并点亮，再点退出）。模式里不用按着 `Ctrl`：单击设备即加选 / 取消加选，按住左键拖动仍是框选；**点或拖到频段行都会把该频段下所有设备一起选中**，整条已全选时再点一次整条取消。批量模式下频段行的展开 / 折叠改用**右键**（左键已经被选中设备占用了）。按住 `Ctrl` 点频段行或类型行也会直接进入这个模式；类型行只负责展开折叠；退出模式不会清空已选设备。
- **改名后即时刷新**：给设备或频段改名后立刻重扫一次网络，树与检查器马上显示新名字，不用等下一轮轮询。
- **跟随选中**：点选一台设备后，列表会自动展开到它并选中；如果它已经在可视区里就不滚动（避免每次同步把列表拽走）。绑定之后设备换了分组，也会重新跟过去。
- **目标频段会保留**：换一台设备当配对源时，已选中的目标频段不会被清空 —— 只有新设备与原来的类型不同时才清空（跨类型绑定没有意义）。
- **一键绑定**：目标槽有值时，底部「绑定」按钮与回车键都会提交。服务端会回传结果码，状态行显示「已绑定到 0A1B」或具体的失败原因（没选源 / 频段不可绑定 / 网络未就绪）。**绑定后目标槽保持不变**，可以接着选下一台设备绑到同一个频段。
- **检查器**：右侧面板顶部是状态 chip（连接状态 / 输入输出 / 频道占用），下面是属性表，底部 2×2 次级动作 + 一根频道占用进度条。占用只对 ME P2P 显示（其它类型压根没有这个概念），剩余低于阈值时进度条转警告色。改名是就地编辑 —— 输入时其余属性继续显示，按 Esc 取消。
- **重命名 / 别名**：为单个 P2P 设备设置自定义名称，也可为整个频段（频段输入端）设置别名，便于识别。
- **分配新频道**：为配对源设备一键分配一个全新的空闲频段并设为输入端。
- **自动配置输入/输出（仅 ME P2P）**：根据外部网络是否连接「ME 控制器」自动判定该 ME P2P 应作为输入端还是输出端，并自动分配频段。
- **高亮即定位**：点「高亮」先关掉界面，再在世界上渲染 P2P 通道（自身 / 输入端 / 输出端使用不同颜色），最后把视角转向目标设备 —— 原来的「定位」按钮已并进这里。转头仍受客户端配置 `rotateHeadOnHighlight` 控制。聊天栏只发送位置信息，不再附带可点击的传送链接。频段节点的高亮会把该频段**输入端与输出端全部**列出来（各带「输入」/「输出」标记）。
- **传送按钮（可选）**：P2P 设备行与类型行的第 4 格是独立的「传送」按钮，由服务端直接执行传送（支持跨维度）。落点到位后客户端会自动点亮这台设备并让视角转向它 —— 这里的转头不看 `rotateHeadOnHighlight`（那项配置只管高亮，传送是玩家主动发起的位移，落点又贴着设备，不转头会完全失去方向感）。只有服务端配置 `allowTeleport = true` 时按钮才会出现，服务端也会对每个传送请求再校验一次。频段节点没有自己的位置，因此不提供传送。
- **跨维度连接**：编码格式携带维度信息，可正确跨维度查找并高亮 P2P 设备。

### ⌨️ 按键一览

| 按键 | 生效场景 | 作用 |
| --- | --- | --- |
| `V` | 手持卡 | 在复制模式 / 配置模式之间切换 |
| `G` | 手持卡且处于复制模式 | 打开粘贴选项面板 |
| Shift + 右键（空气） | 手持卡 | 快速切换模式 |
| Shift + 右键（AE 方块 / 部件） | 复制模式 | 把该设备的配置复制进卡片（原生 AE2 行为），并按设置自动弹出选项面板 |
| 右键（空气） | 复制模式 | 批量粘贴；尚未完成选区时给出提示 |
| 右键（P2P 部件） | 配置模式 | 打开 P2P 配置界面 |

> `V` 与 `G` 均可在「选项 → 控制 → 按键绑定 → 高级内存卡」中修改。

## 📦 安装说明

### 前置要求

| 依赖 | 版本要求 |
| --- | --- |
| Minecraft | `1.21.1` |
| NeoForge | `21.1.219` 或更高（`[21.1.219,)`） |
| Applied Energistics 2 (AE2) | 与 MC 1.21.1 匹配的版本（开发基于 `19.2.17`；`neoforge.mods.toml` 中声明为 `*`） |

> 除以上三项外没有声明其他运行时依赖。Jade、GuideME、JEI 只在开发环境引入以便调试，发行包不依赖它们。

### 安装步骤

1. 从发布页下载最新版本的 `advanced_memory_card-<版本>.jar`。
2. 将 `.jar` 文件放入 Minecraft 的 `mods` 文件夹。
3. 确保已安装上述前置模组（NeoForge 与 AE2）。
4. 启动游戏，在创造模式物品栏「高级内存卡」分组（`advanced_memory_card:advanced_memory_card_tab`）中找到物品 `advanced_memory_card:advanced_memory_card`。

## 🛠 配置说明

模组提供客户端与服务端两套配置文件（位于 `config/` 目录）：

### 服务端配置（`advanced_memory_card-server.toml`，`[server]` 段）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `maxCopyVolume` | `2048` | 复制模式允许的最大区域体积（方块数，范围 1 – `Integer.MAX_VALUE`），超出则拒绝粘贴 |
| `sendHighlightToChat` | `true` | 高亮 P2P 设备时是否在聊天栏发送位置信息 |
| `allowTeleport` | `false` | 是否允许界面上的「传送」按钮把玩家直接传送到 P2P 设备位置（支持跨维度）。关闭时按钮隐藏，服务端也会拒绝传送包 |

### 客户端配置（`advanced_memory_card-client.toml`）

主要用于界面与渲染外观的个性化，按片段组织：

- `[client.highlight]`：`rotateHeadOnHighlight`（高亮时自动转头）、`p2pHighlightDurationSec`（高亮持续时间，1–60 秒）。
- `[client.treeLayout]`：`rowHeight`（行高，默认 14）、`indentWidth`（每级缩进，默认 10）、`channelWarningThreshold`（剩余频道低于此值转警告色）、`nameMaxLength`（名称显示上限）。
- `[client.palette]`：语义色板。`textPrimary` / `textSecondary` / `textTertiary`、`accent` / `accentText`、`rowSelected` / `rowHover`、`surface` / `surfaceHover`、`divider`、`statusOk` / `statusWarn` / `statusDanger`、`chipOkBg` / `chipAccentBg` / `chipWarnBg` / `chipDangerBg`、`overlayBg` / `overlayBorder` / `overlayShadow`。
  > 默认值按对比度挑选：在列表底色 `#ADB0C4` 上全部 ≥ 4.5:1。旧版的 `treeColors` / `panelColors` / `buttonColors` / `panelLayout` 已被 `palette` 取代。
- `[client.copyColors]`：`startPos` / `endPos` / `targetedPos` / `overLimit`，以及 `[client.copyColors.selection]` 下的 `ready` / `first` / `second`。
- `[client.highlightColors]`：`self` / `input` / `output`（P2P 高亮渲染）。
- `[client.itemColors]`：`color`（物品主色）与 `tintColor`（着色色）。

> 颜色为十六进制数值（GUI 类为 ARGB，世界渲染类为 RGB），可直接在配置文件中修改。

## 📖 使用流程速览

### 复制模式

1. 手持高级内存卡处于复制模式，对着源 AE2 设备 **Shift + 右键** 复制其配置（此时会按设置弹出粘贴选项面板，按需勾选）。
2. 对着第一个角落方块 **普通右键** 标记起点（红色）。
3. 对着对角方块 **普通右键** 标记终点（白色），此时进入待粘贴状态（绿色）。
4. 对着空气 **普通右键**，把配置批量应用到区域内所有 AE2 设备。

> 面板可以随时关闭，选项会保留在卡片上；不想每次都弹出就把左侧工具栏的开关切成灰化状态。

### 配置模式

1. 切换至配置模式，对着任意 P2P 隧道部件 **普通右键** 打开配置界面。
2. 在左侧树中浏览 / 搜索网络内的 P2P，选中节点查看右侧详情。
3. 通过详情面板按钮进行重命名、绑定频段、分配新频道、自动配置输入/输出、高亮定位等操作。
4. 需要一次改一批设备时，点底部「批量操作」进批量模式（或按住 `Ctrl` 点频段行 / 类型行直接进入），单击、拖动、点频段行都能整批选中，选完回车绑定。

## 🔧 开发构建（面向开发者）

```bash
# 客户端运行（开发环境）
./gradlew runClient

# 专用服务端运行
./gradlew runServer

# 游戏测试服务端
./gradlew gameTestServer

# 构建发布 jar
./gradlew build

# 生成配方 / 物品模型 / 语言文件
./gradlew runData
```

- 基于 **NeoForge 21.1.219** 与 **ModDevGradle 2.0.140**，Java 21 工具链，Parchment 映射 `2024.11.17`。
- 使用 Mixin（`advanced_memory_card.mixins.json`，`compatibilityLevel: JAVA_21`）做两处扩展：
  - `P2PTunnelPartMixin`：公开 AE2 的 `P2PTunnelPart#setOutput`；
  - `AEBasePartAccessor`：用 `@Accessor` 直写 `AEBasePart#customName` 实现 P2P 改名（绕开 `importSettings` 的副作用）。
- 资源由 `src/main/java/.../datagen` 下的生成器产出到 `src/generated/resources/`：`ModRecipesProvider`、`ModItemModelsProvider`、`ModEnusLangProvider`、`ModZhcnLangProvider`。
