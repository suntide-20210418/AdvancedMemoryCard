一个 Applied Energistics 2（AE2）扩展模组，为 AE2 内存卡提供**批量复制**与**P2P 通道高级配置**两大增强功能。

> **当前版本：`1.1.0-1.12.2`** · Minecraft 1.12.2 / Forge 14.23.5.2860
> 更新内容见 [CHANGELOG.md](CHANGELOG.md)。

## 🌟 功能特性

### 🔧 两种工作模式

模组在物品 NBT 中以「模式」形式存储状态，可随时切换：

| 模式 | 说明 |
| --- | --- |
| **复制模式（Copy Mode）** | 框选一个区域，把已复制的 AE2 设备配置批量粘贴到区域内所有 AE2 方块与部件 |
| **配置模式（P2P 通道管理）** | 对着 P2P 隧道部件右键打开图形化界面，对网络内的 P2P 通道集中管理与配置 |

### 📋 复制模式（Copy Mode）

- **区域批量复制**：先把单个 AE2 设备的配置复制进卡片，再框选两个对角方块确定区域，对着空气右键即可把配置批量应用。
- **支持 AE2 方块与部件**：区域内所有 `AEBaseTile`（ME 控制器、接口、存储总线等）以及 `IPartHost` 上的所有部件都会被处理。
- **体积上限保护**：区域体积超过服务端配置 `maxCopyVolume`（默认 2048 个方块）时会被拒绝并提示，避免误选超大范围造成卡顿。
- **可视化选择框**：框选过程用不同颜色实时提示状态（红色=选第一点 / 白色=选第二点 / 绿色=待粘贴），目标方块、超范围方块也有独立配色。
- **实时状态提示**：物品 tooltip 与聊天栏会显示已标记坐标、区域大小、实际粘贴数量。
- **复制后自动弹出选项面板**：每次复制成功后，按卡片上的开关决定是否立即弹出面板，方便顺手调整这次要粘贴什么。

#### 粘贴选项（7 项，按卡保存）

| 选项 | 作用 |
| --- | --- |
| 设置 | 输出面、模糊模式等通用配置 |
| 优先级 | 存储总线 / 接口等的优先级 |
| 配置物品 | 过滤、标记等配置槽内容 |
| 样板 | 接口的样板槽 |
| P2P 类型 | P2P 隧道类型（勾选且与目标不同时会拆掉重建） |
| P2P 频率 | P2P 频段 |
| 名称 | 方块的自定义名 |

- **未勾选的项保持目标原值**，不是「清空」——这是与 AE2 原生内存卡最大的区别，也是本模组不复用 `uploadSettings` 的原因。
- **未配置过的卡片默认全不选**：第一次使用请按 `G` 打开面板勾选；掩码为空时粘贴只提示、不消耗选区。
- **「升级」不在选项里**：AE2 1.12.2 的 `downloadSettings` 从不导出 `upgrades`，卡片里没有这段数据。
- **「名称」对方块有效**：部件侧的 `downloadSettings` 不写 `display` 段，因此部件名保持原样。

### 🕸 配置模式（P2P 通道管理）

对着任意 **P2P 隧道部件**右键即可打开配置界面，对当前 AE 网络内的所有 P2P 设备进行可视化管理：

- **P2P 树形列表**：自动扫描所在网络，按类型 / 频道分组展示所有 P2P 设备，支持展开折叠与搜索过滤。
- **详情面板**：选中节点后展示类型、频段、输入/输出状态、连接状态等信息。
- **重命名 / 别名**：为单个 P2P 设备设置自定义名称，也可为整个频道（频段输入端）设置别名；名称会立即落盘。
- **绑定频段**：绑定到指定 4 位十六进制频段（如 `0A1B`）。目标频段已有其他输入端时当前设备自动作为输出端；`0000`（未连接）不是可绑定目标，会被拒绝。
- **分配新频道**：为当前选中的 P2P 一键分配一个全新的空闲频段并设为输入端。
- **自动配置输入/输出（ME P2P）**：根据外部网络是否连接「ME 控制器」判定该 ME P2P 应作为输入端还是输出端。
- **高亮定位**：在世界中高亮渲染 P2P 通道（自身 / 输入端 / 输出端不同颜色），可选自动转头面向目标，并在聊天栏发送位置与传送链接。
- **跨维度定位**：位置编码携带维度信息，可正确跨维度查找并高亮 P2P 设备。

### ⌨️ 按键一览

| 按键 | 作用 |
| --- | --- |
| `V` | 手持卡片时切换「复制模式 / 配置模式」 |
| `G` | 复制模式下打开粘贴选项面板 |
| `Shift + 右键` | 复制模式下：把目标设备配置复制进卡片（AE2 原生行为）；其它情况下：快速切换模式 |

> `V` 与 `G` 都可以在「选项 → 控制 → 按键绑定 → 高级内存卡」中修改。

## 📦 安装说明

### 前置要求

| 依赖 | 版本要求 |
| --- | --- |
| Minecraft | 1.12.2 |
| Forge | 14.23.5.2860 或更高 |
| Applied Energistics 2 | AE2 Extended Life（CurseForge `570458`，开发基于文件 `6302098`） |

> 模组直接引用 `appeng.*` 的 P2P 与方块实体实现，AE2 是**必需**依赖，缺失时无法加载。

### 安装步骤

1. 从发布页下载 `advanced_memory_card-1.1.0-1.12.2.jar`。
2. 放入 Minecraft 的 `mods` 文件夹。
3. 确保已安装上述前置模组。
4. 启动游戏，在创造模式物品栏「高级内存卡」分组中找到该物品。

## 🛠 配置说明

配置文件位于 `config/advanced_memory_card/`：

### 服务端配置（`server.cfg`，`[server]` 段）

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `maxCopyVolume` | `2048` | 复制模式允许的最大区域体积（方块数），超出则拒绝粘贴 |
| `sendHighlightToChat` | `true` | 高亮 P2P 设备时是否在聊天栏发送位置信息与传送链接 |

### 客户端配置（`client.cfg`）

用于界面与渲染外观的个性化，分组包括：

| 分组 | 内容 |
| --- | --- |
| `client.highlight` | 高亮时是否自动转头、高亮持续时间 |
| `client.treeColors` / `client.treeLayout` | P2P 树的背景 / 选中 / 悬停颜色，缩进、行高、图标间距、名称长度限制 |
| `client.panelColors` / `client.panelLayout` | 详情面板的背景与文字颜色、状态色、布局尺寸 |
| `client.buttonColors` | 通用按钮的默认 / 悬停 / 按下 / 文字颜色 |
| `client.copyColors` | 复制模式选择框的起止点、目标、超范围与三种状态颜色 |
| `client.highlightColors` | P2P 高亮的自身 / 输入端 / 输出端颜色 |
| `client.itemColors` | 物品主色与着色色 |

> 颜色为十六进制数值（GUI 类 ARGB，渲染类 RGB），可直接编辑配置文件；改完重启游戏生效。

## 📖 使用流程速览

### 复制模式

1. 手持卡片处于复制模式，对着源 AE2 设备 **Shift + 右键** 复制其配置。
2. （可选）按 `G` 或让面板自动弹出，勾选这次要应用的项。
3. 对第一个角落方块 **普通右键** 标记起点（红色）。
4. 对角方块 **普通右键** 标记终点（白色），进入待粘贴状态（绿色）。
5. 对着空气 **普通右键** 批量应用到区域内所有 AE2 设备。

### 配置模式

1. 切换到配置模式，对着任意 P2P 隧道部件 **普通右键** 打开界面。
2. 左侧树中浏览 / 搜索网络内的 P2P，选中节点查看右侧详情。
3. 通过详情面板按钮进行重命名、绑定频段、分配新频道、自动配置输入/输出、高亮定位等操作。

## 🔧 开发构建（面向开发者）

```bash
# 客户端运行（开发环境）
./gradlew runClient

# 专用服务端运行
./gradlew runServer

# 构建发布 jar
./gradlew build
```

- 构建基于 **ForgeGradle 3**，需要 **JDK 8**；Gradle 版本由 `gradle/wrapper` 固定为 4.9。
  本机若默认不是 JDK 8，用 `JAVA_HOME` 或 `-Dorg.gradle.java.home=<JDK8 路径>` 指定，不要把路径写进 `gradle.properties`（CI 上会直接失败）。
- **国内镜像默认关闭**：`build.gradle` 里的阿里云 / BMCLAPI 仓库只在加 `-DcnMirror=true` 时启用。
  BMCLAPI 对部分工件的 302 指向一个已失效的域名，CI 上 DNS 解析失败且 FG3 不会回退下一个仓库。
- 通过 `src/main/resources/META-INF/accesstransformer.cfg` 访问 AE2 的包级私有成员（例如 `PartP2PTunnel#setOutput`），反射入口集中在 `P2PManager`。
- 本分支没有 Mixin 与 datagen：界面资源是手绘贴图（`assets/advanced_memory_card/textures/gui/`），模型与语言文件直接维护在 `src/main/resources` 下。
